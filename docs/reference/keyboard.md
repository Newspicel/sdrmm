---
title: Keyboard controls
description: Canvas, tuning, squelch, editing, and frequency-dial shortcuts.
---

Shortcuts target the selected node and pause while typing in inputs. Press `?` inside SDRmm for the live cheat sheet.

| Keys | Action |
|---|---|
| `←` / `→` (`Shift` ×10) | Tune one (or ten) steps |
| `[` / `]` | Smaller / larger tuning step |
| `f` | Focus dial (`Enter` to type; `←`/`→` digit, `↑`/`↓` value, `PgUp`/`PgDn` ×10, `Home`/`End`, `0`–`9`) |
| `,` / `.` | Previous / next channel |
| `m` / `M` | Cycle analog mode (NFM, WFM, AM, SSB) |
| `-` / `+` (`=`), `s` | Squelch ±2 dB, toggle squelch |
| `1`–`9`, `p`, `v`, `z` | Select nth node, pin to Rack, swap Patch/Rack, zoom node |
| `Ctrl`/`⌘ Z`, `Shift Z`/`Y`, `C`, `V`, `Backspace` | Undo, redo, copy, paste, delete |
| `Space` | Hold to talk (PTT) |
| `?`, `Esc` | Help, close/deselect |

Select a node before mouse-scrolling its dial; hold `Ctrl`/`⌘` to disable scroll-tuning.
